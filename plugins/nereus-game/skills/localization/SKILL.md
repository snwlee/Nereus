# localization

nereus:common 규칙을 따른다. 담당 에이전트: architect.
**엔진과 무관하다** — Luau 든 C# 이든 같은 규칙으로 소스를 훑는다.

로블록스 트래픽은 해외 비중이 크다. 그런데 현지화 결함은 출시 **후에** 드러나고,
그때는 고치는 비용이 몇 배가 된다. 이 스킬은 **번역을 실행하지 않고** 번역하면 깨질 곳을 지금 찾는다.

## 0. 언어 집합은 `locales.json` 이 단일 출처다

```bash
cat "${CLAUDE_PLUGIN_ROOT}/locales.json"
```

기본값은 로블록스 상위 시장 8종: EN · KO · JA · PT-BR · ES · ZH · FR · DE.
언어를 늘리는 것은 이 파일 한 줄이다 — 검사기를 고치지 않는다.

각 로케일의 `expansion` 은 **영어 대비 평균 문자열 길이 비의 추정치**다.
실측이 아니므로 파일에 값으로 두고 출처를 `note` 로 남긴다. 코드에 박으면 나중에
실측으로 고칠 때 어디를 고쳐야 하는지 모른다.

**알 수 없는 로케일은 기본값으로 떨어지지 않고 던진다.** 조용히 건너뛰면
그 로케일이 검사되지 않은 채 통과한다.

## 1. 검사

`scanL10n` 을 부른다 (`lib/l10n-scan.mjs`). 입력은 넷이다:

| 인자 | 뜻 |
|---|---|
| `tables` | 로케일별 문자열 테이블. `{ en: { "hud.jump": "Jump" }, ko: { ... } }` |
| `sources` | 훑을 소스. `[{ file, text }]` |
| `maxWidth` | UI 폭(문자 수). 장르 프로파일의 `l10n.maxWidth` 를 쓴다. 0 이면 폭 검사를 하지 않는다 |
| `accessor` | 문자열 테이블 접근자. 기본 `L(` |

| 위반 코드 | 뜻 |
|---|---|
| `hardcoded` | 접근자를 거치지 않은 사용자 노출 문자열 |
| `missing-key` | 기준 로케일에 있는 키가 그 로케일에 없다 |
| `overflow` | 확장률을 곱하면 `maxWidth` 를 넘는다 |

## 2. 하드코딩 판정 기준

사용자 노출로 보는 조건: 한글·가나·한자가 있거나, 두 글자 이상 단어 뒤에 공백이 오는 문자열.
식별자·경로·포맷 토큰을 사용자 문장으로 오인하지 않기 위한 최소 조건이다.
주석 줄(`--`, `//`, `#`)과 접근자가 있는 줄은 건너뛴다.

느슨한 쪽으로 틀리면 무해한 경고가 늘고, 빡빡한 쪽으로 틀리면 진짜 문자열을 놓친다.
**놓치는 쪽이 더 나쁘므로** 애매하면 잡는다.

## 3. 숫자·복수형·날짜

문자열 테이블에 문장을 통째로 넣는다. `"You have " .. n .. " coins"` 처럼 조각내면
복수형·어순이 다른 언어에서 고칠 방법이 없다. 자리표시자를 쓴다.
