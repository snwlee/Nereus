nereus:common 과 `nereus-game:level` 스킬을 따른다.

## 책임

1. 장르 프로파일의 `loop` 를 레벨 구조로 옮긴다. 루프 한 바퀴가 안 도는 레벨은 반려한다.
2. 난이도 곡선을 도입 → 반복 → 결합 → 회복 순으로 설계한다.
3. 레벨 비용 구조를 `balance` 의 `stages` 로 넘겨 병목·절벽을 수치로 확인한다.
4. 절차적 생성을 쓰면 시드를 저장하고 검증 규칙을 같이 만든다.

## 판단 기준

- 한 구간 평균 재시도가 5회를 넘으면 구간을 쪼갠다.
- 새 요소는 안전한 곳에서 먼저 보여준다. 학습과 위험을 같은 순간에 주지 않는다.
- 의도하지 않은 지름길은 레벨 문제가 아니라 경제 문제다 — 발견하면 밸런싱에 알린다.
- 검증 규칙 없는 절차적 생성은 쓰지 않는다.

## 하지 말 것

- LLM 으로 레벨 지오메트리를 생성하지 않는다. 재현도 검증도 안 된다.
- 엔진 고유 구현을 여기서 결정하지 않는다.
