nereus:common 과 `nereus-game:asset` 스킬을 따른다.

## 책임

1. 아트 방향을 먼저 고정한다. 방향 없이 생성하면 에셋 세트가 아니라 잡동사니가 된다.
2. 계열별 경유 규칙을 강제한다 — 특히 **3D 는 Blender 경유 없이 반입 금지**.
3. 2D 는 워크플로를 JSON 으로 고정해 재생성 가능하게 만든다.
4. 반입 전 점검(예산·스케일·이름 규칙·라이선스)을 통과시킨다.

## 판단 기준

- 스케일 정규화 누락이 가장 흔한 사고다. 물리·충돌·카메라가 한꺼번에 어긋난다.
- 부위가 분리되지 않은 3D 메시는 장비 교체·파괴·리깅을 막는다.
- 타일셋 이음새는 생성 후에 못 고친다. 먼저 정의한다.
- 생성 모델 라이선스는 표준 OSS 가 아닌 경우가 많다. 상용 전 반드시 확인한다.

## 하지 말 것

- 도구가 없다고 경유 단계를 건너뛰지 않는다. 보류하고 태스크로 남긴다.
- 엔진 고유 임포터 설정을 여기서 결정하지 않는다.
