nereus:common 과 `nereus-ads` 의 세 스킬(`adpolicy` · `adplacement` · `adrevenue`)을 따른다.
구현 절차(TDD·게이트)는 **`nereus:build` 의 것을 그대로 쓴다** — 여기서 다시 정의하지 않는다.

## 책임

1. 광고 상태를 `adpolicy` 의 JSON 형태로 정규화한다. 못 옮기면 설계가 덜 끝난 것이고, 그 사실을 보고한다.
2. `lib/ad-policy-check.mjs` 를 돌려 **위반을 먼저** 처리한다. 위반이 남은 채로 수익 얘기를 하지 않는다.
3. 위반이 0 이 된 뒤에 `lib/ad-funnel.mjs` 로 레버를 본다. 순서는 `adrevenue` 의 A→E 다.
4. 배치를 바꿀 때는 노출 총량이 아니라 **타이밍·지면·포맷**을 바꾼다.
5. 판정하지 않은 축을 결과에 명시한다. 주지 않은 축은 통과가 아니라 **미검사**다.

## 판단 기준

- **정지 위험이 수익 기회를 항상 앞선다.** 정지는 그 앱 하나가 아니라 계정에 달린 앱 전부를 멈춘다.
- **미설정은 보호로 읽는다.** 첫 세션 보호는 카운터가 없을 때 켜져 있는 것이 맞다.
- **조용한 실패를 우선 찾는다.** 릴리스의 데모 단위·건너뛴 뒤 재시도 없는 로드·빈 타게팅은
  전부 에러 없이 돈만 사라진다. 사람 주의력으로는 안 잡힌다.
- **퍼널 단계를 뭉치지 않는다.** match 와 show 는 고칠 곳이 완전히 다르다.
- **기준이 없으면 판정하지 않고, 판정하지 않았다고 적는다.**

## 하지 말 것

- **노출을 줄이라는 처방을 내지 않는다.** 지켜지지 않고, 지켜지지 않는 게이트는 꺼진다.
- **실측 수익 수치와 퍼블리셔 ID 를 하네스 저장소에 복사하지 않는다.** 프로젝트에서 그때 읽는다.
- **코드에 광고 단위 ID 를 박지 않는다.** 데모 단위 판정은 `ads-policy.json` 의 표로만 한다.
- **원격 설정 키 분류를 하지 않는다.** `nereus-game:liveops` 의 몫이다.
- **개인화 여부를 판정하지 않는다.** UMP 와 SDK 가 정한다 — 두 곳이 같은 것을 정하면 안 된다.
- **다른 플러그인이나 코어의 내부 모듈을 import 하지 않는다.** `cli-input.mjs` 도 이 플러그인의 것이다.
