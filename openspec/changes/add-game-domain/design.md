# design — add-game-domain

## 구조

```
plugins/nereus-game/
  profiles/                     ← 장르. 데이터지 코드가 아니다
    sim-tycoon.json
    obby-platformer.json
  lib/
    profiles.mjs                ← 로드·검증 (테스트 대상)
    balance-sim.mjs             ← 결정론적 경제 시뮬레이터 (테스트 대상)
    roblox-stack.mjs            (1차)
    unity-stack.mjs             ← 신규 (테스트 대상)
  skills/
    roblox/ level/ narrative/ gameux/ asset/ balance/
  agents/                       ← CCGS 채굴 → Nereus 포맷으로 재작성
  nereus-extension.json         ← 라우트 6종
```

## 결정 1: 장르는 분기가 아니라 데이터

스킬 안에서 `if 타이쿤 / else 오비` 로 갈리면 장르가 늘 때마다 5개 스킬을 전부 고쳐야 한다.
프로파일을 데이터로 두면 장르 추가가 **파일 한 장**이다.

프로파일이 담는 것:

| 키 | 뜻 | 쓰는 곳 |
|---|---|---|
| `genre` | 식별자 | 전부 |
| `loop` | 핵심 루프 단계 배열 | level · balance |
| `metrics` | 이 장르에서 봐야 하는 지표 | balance · finish 롤아웃 |
| `balance` | 시뮬레이터 입력 기본값 | balance-sim |

`sim-tycoon` 의 루프는 `수집 → 판매 → 재투자 → 확장`, `obby-platformer` 는 `도전 → 실패 → 재시도 → 통과`다.
두 장르의 실패 양상이 다르다 — 타이쿤은 **병목**(다음 단계가 도달 불가), 오비는 **난이도 절벽**(연속 실패 구간).
그래서 시뮬레이터는 한 종류의 판정만 하지 않는다.

## 결정 2: 밸런싱은 코드다

이 층에 쓸 만한 오픈소스가 없다는 것이 조사 결론이었다. 직접 만들되, **결정론적**으로 만든다.
난수를 쓰면 시드를 입력으로 받는다. 그래야:

- 같은 경제 정의에 같은 결과 → 회귀 테스트가 성립한다
- 수식을 고쳤을 때 무엇이 달라졌는지 diff 로 보인다
- finish 게이트가 "밸런스가 깨졌다"를 기계적으로 판정할 수 있다

체크리스트 스킬이었다면 이 셋 중 아무것도 못 한다.

## 결정 3: 도메인은 엔진을 모른다

내러티브·UX·밸런싱·에셋·레벨 지식에 Luau 나 C# 을 박으면, 2D 폰게임을 할 때 같은 스킬을 다시 써야 한다.
사용자가 "메인은 없고 다 대응해야 한다"고 했으므로 이건 가정이 아니라 요구다.

테스트로 강제한다 — 도메인 스킬 본문에서 엔진 고유 토큰(`game.Players`·`:GetService`·`MonoBehaviour`·
`UnityEngine`)을 찾으면 실패한다. 문서 규칙은 지켜지지 않지만 테스트는 지켜진다.

## 결정 4: 무결성 테스트를 이식보다 먼저 깐다

1차에서 같은 종류의 결함을 **세 번** 놓쳤다.

| 결함 | 단위 테스트 | 실제 |
|---|---|---|
| 확장 로더를 아무 데서도 호출하지 않음 | 초록 | 런타임에서 확장이 없는 것과 같음 |
| `enabledPlugins` 형태를 지어낸 픽스처 | 초록 | 프로덕션에서 항상 빈 결과 |
| 라우트가 없는 스킬을 가리킴 | 초록 | 설치하면 없는 스킬을 부르라고 지시 |

공통점은 "선언한 것이 실재하는지 아무도 검사하지 않았다"는 것이다. 이번엔 이식 분량이 훨씬 크므로
T1 에서 검사부터 만든다. 검사가 먼저 실패하고, 이식이 그것을 초록으로 만든다.

## 결정 5: CCGS 는 재작성이지 복사가 아니다

`ux-design` 989줄, `design-system` 871줄을 그대로 들이면 스킬 하나가 Nereus 코어 스킬 전체보다 커진다.
가져오는 것은 **판단 기준과 체크리스트**고, 버리는 것은 스튜디오 조직 전제·CCGS 자체 워크플로 참조·
Nereus 에 이미 있는 게이트다. 각 스킬을 120줄 안팎으로 압축한다.

MIT 귀속은 `NOTICE` 에 이미 있고 유지한다.

- Windows 머신의 ComfyUI·Blender 설치 여부 — `asset` 스킬은 "도구 호출 계약"까지만 만들고
  실제 모델 실행은 3차. `nereus:setup` 탐지 항목으로 넘긴다.
- RTX 3080(10~12GB)에서 TRELLIS·YuE 실구동 — 3차 착수 전 실측.
