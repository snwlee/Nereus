# add-game-impact

## Why

사운드는 두 층으로 덮였다 — `asset` 이 만들고 `sound` 가 예산·커버리지를 판정한다.
그런데 **임팩트(타격감·게임필)** 는 아직 `gameux` §4 의 네 줄이 전부다:
입력 지연 100ms, 입력 버퍼, 실패 피드백, 흔들림 약하게.

네 줄로는 판정이 안 된다. 지금 구조에서 다음이 전부 통과한다:
- 히트스톱이 너무 길어 게임이 끊겨 보여도 아무도 막지 않는다
- 스크린셰이크가 동시에 세 개 겹쳐 화면이 무너져도 통과한다
- 파티클이 모바일 예산을 넘겨도 도메인 게이트가 없다
- **이펙트만 터지고 소리가 없어도** 통과한다 — 절반만 만든 연출이다
- 모션 감소 설정에 대한 대체가 없어도 통과한다

## What Changes

- `lib/impact-budget.mjs` — 결정론적 임팩트 검사기. 히트스톱 총량, 동시 셰이크 진폭,
  파티클 동시 수, **사운드 큐 교차 검증**, 피드백 층 수, 입력 버퍼·캔슬 윈도우,
  모션 감소 대체를 수치로 판정한다.
- 장르 프로파일 4종에 `impact` 를 **선택 키로** 추가한다. 오비와 PvP 는 필요한 타격감이 다르다.
- `skills/impact/SKILL.md` + 라우트 1개.
- `gameux` §4 에 impact 로 넘기는 포인터를 남긴다 (지우지 않는다 — 조작감 타이밍은 UI 축에서도 필요하다).

**핵심은 교차 검증이다.** `sound` 가 이미 큐를 선언하므로, 임팩트 큐마다 대응 사운드 큐가
있는지 기계적으로 확인할 수 있다. 소리 없이 터지는 이펙트는 도메인 두 개가 각각 초록인데
게임은 나쁜, 정확히 그 종류의 결함이다.

## Impact

- 영향 스펙: `game-harness` (요구사항 2개 추가)
- 영향 코드: `plugins/nereus-game/{lib,skills,profiles}/**`, `nereus-extension.json`,
  `skills/gameux/SKILL.md`(포인터 한 줄)
- **코어 `plugins/nereus` 는 바뀌지 않는다.**
