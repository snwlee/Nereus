# design — add-switch-nda

## 결정 1: 막는 것은 "NDA 경로"가 아니라 "NDA 경로 + 외부 전송"

NDA 파일을 읽거나 고치는 것을 막으면 그 플랫폼 개발 자체가 불가능해진다. 위반이 일어나는 지점은
**내용이 밖으로 나가는 순간**이다. Nereus 에서 그 지점은 셋이다.

| 경로 | 막는 방법 |
|---|---|
| review 스테이지가 `codex`·`agy`·`ocr` 에 diff 를 넘긴다 | PreToolUse 가 Bash 명령에서 NDA 경로 + 외부 도구 조합을 잡는다 |
| `curl`·`gh` 로 내용을 올린다 | 같은 훅이 같은 규칙으로 잡는다 |
| 모델이 파일을 읽어 컨텍스트에 넣는다 | **막을 수 없다.** 이 세션의 모델은 로컬이 아니다 |

세 번째는 기술로 못 막는다. 그래서 Switch 스킬이 **플랫폼 추상화**를 요구한다 —
게임 로직을 플랫폼 무관 층에 두고 `Platform/Switch/` 를 얇게 유지하면, 모델이 읽어야 할 NDA 코드가
거의 없어진다. 경계 훅은 사고를 막고, 추상화는 사고 면적을 줄인다. 둘 다 필요하다.

## 결정 2: 차단이 기본이다

경고로 두면 언젠가 지나간다. NDA 위반은 되돌릴 수 없고 계약 문제가 된다.
설정으로 `warn` 으로 낮출 수 있게 하되 기본값은 `block` 이다. 낮추는 것은 의식적 행위여야 한다.

## 결정 3: Lotcheck 본문은 저장소에 없다

Lotcheck 체크리스트 항목 자체가 NDA 다. 공개 저장소에 넣을 수 없다.
`.nereus/lotcheck/`(gitignore 대상)에서 읽고, 없으면 스킬이 **절차만** 안내한다.
"체크리스트를 여기 두면 하네스가 기계적으로 훑는다"까지가 공개 가능한 범위다.

## 결정 4: 외부 호출은 전부 주입

`luau-exec.mjs` 가 `fetch` 를 직접 부르면 테스트가 네트워크와 자격증명에 묶인다.
HTTP 를 인자로 받으면 상한 초과·자격증명 부재·폴링 종료 같은 분기를 전부 키 없이 검증할 수 있다.
이것이 "게이트를 만들었는데 돌려본 적 없음"을 막는 유일한 방법이다.

## 결정 5: 리뷰어 헬스체크는 코어에 넣는다

`agy` 는 PATH 에 있고 무응답 후 exit 0 을 낸다. `ocr delegate` 는 워크스페이스만 본다.
"설치돼 있음"과 "쓸 수 있음"이 다르다는 것은 게임 플러그인 문제가 아니라 하네스 공통 결함이다.
2차까지 두 사이클 연속 2차 의견 없이 종결했고, 그때마다 계획은 초록이었다.

프로브는 짧고 타임아웃이 있어야 한다 — 헬스체크가 리뷰보다 오래 걸리면 의미가 없다.

## 이번 사이클에서 반복하지 않을 것

1차·2차에서 "선언했는데 실재하지 않음"을 네 번 만났다(미배선 확장점 · 가짜 픽스처 · dangling route ·
불필요한 export). 이번에도 같은 순서를 쓴다 — **검사를 먼저 깔고 구현이 그것을 초록으로 만든다.**
특히 NDA 훅은 `hooks.json` 에 배선되지 않으면 존재하지 않는 것과 같다. 배선 검사를 태스크에 넣는다.
