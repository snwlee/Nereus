# Nereus 소셜 프리뷰 — 방향 브리프 v2 (밧줄 제어 콘셉트)

## 왜 바꾸는가
현재 채택본은 범고래 몸에 빛나는 기하학적 링이 감긴 그림이다. 은유가 "이미 구속된 몸"에서
멈춘다. 사용자 제안: **네레우스 신이 빛나는 밧줄로 범고래를 제어하는 장면.**
이쪽이 제품을 직역한다 — 범고래 = 날것의 힘(Claude), 빛나는 밧줄 = 하네스(이 도구),
그리고 신화 훅("붙잡고 놓지 않아야 진실을 말한다")이 그림 안에서 실제로 일어난다.
태그라인이 `HARNESS FOR CLAUDE CODE` 이므로 그림과 문구가 같은 것을 말하게 된다.

## 실행 변형: (A) 확정 — Gemini 방향 라운드가 (B)·(C) 를 전면 기각
소셜 카드는 300~400px 로 축소되고 좌측 45%는 텍스트가 점유한다. 이 제약에서 복수 피사체는
시각 노이즈와 생성 결함을 필연적으로 부른다. **단일 피사체 + 단일 장력 선**만 남긴다.

### 확정 스펙 (방향 라운드 지정)
- **밧줄 기점: 좌하단 모서리 절대 앵커 (x=0, y=580~620).** 거기서 우상단 범고래를 향해
  **40~45도 대각선 장력 벡터**로 뻗어 고래의 저항 방향과 팽팽히 맞선다. "텍스트 아래 어딘가"
  같은 모호한 기점은 문구 베이스라인과 충돌한다.
- **밧줄 단면 최소 24px** (1280px 원본 기준). 얇으면 300px 축소 시 안티앨리어싱으로 선이 소멸한다.
- **접촉부에 깊은 앰비언트 오클루전** — 살 눌림 그림자를 파서 발광 글로우보다 **기계적 결속력이
  먼저** 읽히게 한다.
- **좌측 45% 배경 휘도를 CIELAB L* 10 이하로 고정.** 광원 위치로 어둠을 설명하되 렌더링 편차로
  텍스트 대비가 무너지지 않게 하한을 못 박는다. **밧줄의 발광 산란광이 텍스트 안전 영역 안으로
  번지지 않게** 광학적으로 차단한다.
- **팔레트 위계**: 시안–민트(#7fe3d4)는 "통제·제어 신호"의 기능색으로 한정한다. 주광원 페일
  골드는 채도를 탈색에 가깝게 눌러, 시선의 1순위가 **밧줄의 장력**에 꽂히게 한다.

## (참고) 기각된 변형
소셜 카드는 300~400px 로 축소돼 뜨고, 좌측 45%는 텍스트(NEREUS + 2줄 태그라인)가 점유한다.
남은 공간에 피사체를 몇 개까지 놓을 수 있는지가 쟁점이다.

- **(A) 밧줄만 — 화면 밖에서 들어온다.** 신은 그리지 않는다. 빛나는 밧줄·고삐가 좌측 하단
  프레임 밖(텍스트 영역 아래)에서 뻗어와 범고래를 감고 당긴다. 제어하는 존재는 암시된다.
  장점: 피사체 하나 유지, 해부 오류 없음, 밧줄이 좌우를 연결하는 선이 된다(이전 라운드가
  요구한 "좌우 분리 해소"를 구조로 해결). 단점: "신"이 없어 신화성이 약해질 수 있다.
- **(B) 손·팔만 보인다.** 프레임 하단 또는 우측에서 신의 손과 팔뚝만 등장해 밧줄을 쥔다.
  장점: 제어 주체가 명시되고 얼굴 렌더 리스크가 없다. 단점: 손은 생성 모델의 최대 약점이다.
- **(C) 신의 전신·상반신.** 파도 위에 선 바다의 노인이 밧줄을 당기고 범고래가 저항한다.
  장점: 서사가 가장 강하다. 단점: 300px 에서 두 피사체가 서로 뭉개진다. 텍스트 45%를
  빼면 두 인물을 놓을 폭이 없다. 얼굴·손 해부 오류 위험.

세 변형 중 **소셜 카드라는 매체 제약에서 가장 강한 것을 골라 이유와 함께 지정**해달라.
고른 변형에 대해서만 구도·명도·팔레트를 비평해달라.

## 유지되는 것 (직전 채택본에서 이미 검증된 결정)
- 회화풍(유화풍) 다크 판타지. 기존 README 히어로와 같은 세계관.
- 브리칭하는 범고래는 완만한 아크. 등 곡선과 시선이 좌측 텍스트를 감싸며 시선 루프를 닫는다.
- 광원 2개를 색온도로 분리: 주 광원 = 신광·왕관(차가운 화이트–페일 골드, 우측 후방),
  부 광원 = 밧줄의 발광(시안–민트 #7fe3d4, 좁고 날카롭게).
- 림 라이트는 페일 골드로 단일화. 시안은 전면 앰비언트 반사광에만.
- 좌측 텍스트 영역은 역광의 암부. 인위적 블랙 페이드 금지, 광원 위치로 어둠을 설명한다.
- 해무는 원경과 고래 사이에만. 물보라는 텍스트 글자 면과 절대 겹치지 않는다.
- 우하단 구석은 평범한 물로 비워 둔다(생성 워터마크 자리).
- 텍스트는 이미지에 넣지 않는다 — 별도로 합성한다. 그림에는 글자를 하나도 그리지 않는다.
- 1280×640, 1MB 미만. 300~400px 축소 시 실루엣이 읽히는 것이 합격 기준.

## 밧줄의 형태 언어 (여기가 핵심)
장식용 네온 줄이 아니다. **제어 장치**로 읽혀야 한다.
- 굵고 팽팽하다. 장력이 보인다 — 감긴 지점에서 살이 눌리고 접촉 그림자가 생긴다.
- 발광은 좁고 날카롭게, 뮤트된 틸로 환경광에 속한다. 배경에서 뜬 형광색 금지.
- 축소했을 때 "몸을 감고 당기는 선"으로 실루엣 단위에서 읽혀야 한다.
- 미세한 코드 글리프·룬을 밧줄에 새기지 않는다(축소 시 픽셀 노이즈).

## 타이포그래피 (합성 단계, 채택본에서 검증된 수치를 그대로 승계)
그림에는 글자를 그리지 않는다. 아래는 ImageMagick 합성 파라미터다.
- 폰트 `Avenir Next`(지오메트릭 산세리프). 워드마크 `NEREUS` pointsize 81 / kerning 22 →
  실측 435×112, 색 #f2e8cf.
- 태그라인 2줄 `HARNESS FOR` / `CLAUDE CODE` pointsize 22 / kerning 9 / strokewidth 1.1,
  색 #c6d2d0. 캡하이트 32 → 계층비 3.5:1.
- 좌측 패딩 94px(최소 48px 규칙 충족), 블록 수직 중심 Y=320
  (워드마크 베이스라인 330, 태그라인 380·422).
- 텍스트 아래 소프트 섀도 #04090b, blur 7, alpha 70%, offset +3+4. 외곽 블러 0 — 날카로운 엣지 유지.
- 대비 보강용 광학 헤이즈 매트(타원 blur 120, 최대 45%) — 하드 엣지 없음.

## 문구 확정: HOLD FAST FOR THE TRUTH
`HARNESS FOR CLAUDE CODE` 를 대체한다. 네레우스 신화의 장치(붙잡고 놓지 않아야 진실을 말한다)와
이 하네스의 evidence 게이트(검증 없이는 "됩니다"를 말할 수 없다)가 같은 문장이 된다.
그림이 문구를 설명하고 문구가 그림을 설명한다. 도구의 정체는 리포 description 이 맡는다.

## 타이포 최종 수치 (합성)
워드마크 `NEREUS` ps81 / kern22 → 435×112, #f2e8cf. 베이스라인 y=322.
태그라인 2줄 `HOLD FAST` / `FOR THE TRUTH` ps26 / kern11 / strokewidth 1.5 → 237×37, 336×37,
#ccd8d6. 베이스라인 y=379, 424. 좌측 여백 94px. 계층비 3.0:1.
텍스트 섀도 #04090b blur7 alpha70% offset+3+4. 좌측 암부는 **심 없는 선형 램프**
(2px 그라데이션을 확대 → pow 2.2 → alpha 60%)로 깔았다. 타원 매트는 평탄해 보여 폐기했고,
`gradient:` + `-rotate` 조합은 x=640 에 하드 심을 만들어 폐기했다.
측정 대비: 배경 대 텍스트 9.4~13.9:1 (WCAG AAA 7:1 초과).

## Ruling — 워드마크 서체를 세리프로 바꾸라는 지적은 거절 (2026-09-07)
밧줄 콘셉트 렌더 라운드에서 "고전 조각상과 지오메트릭 산세리프가 불협화음이니 날카로운 세리프나
클래식 디스플레이로 교체하라"(MEDIUM)는 지적이 나왔다. 거절한다 — **같은 비평가가 앞선 라운드에서
디도네 세리프를 직접 기각했다**: "유기적 판타지 일러스트와 만나 게임 아티팩트처럼 보인다"(HIGH),
"헤어라인이 360px 에서 뭉개지고 에일리어싱이 발생한다"(HIGH). 타입 축에서 3번째 반전이며 결함
지적이 아니라 취향 순환이다. 360px 실측에서 현재 산세리프는 워드마크·태그라인 모두 판독된다.
