# Nereus GitHub 소셜 프리뷰 — 방향 브리프 (확정)

## 산출물
1280×640 PNG, 1MB 미만. GitHub Settings → Social preview 업로드용.
**피드에서 300~400px 폭으로 축소돼 뜨는 것이 주 용도.** 모든 결정의 기준은 그 크기에서의 가독성이다.

## 무엇인가
Nereus = Claude Code 개발 하네스 플러그인. 인터뷰 → 스펙 → TDD 빌드 → 병렬 리뷰 → 마무리.
훅이 실제로 편집을 차단한다. 개인용이지만 공개 저장소.

## 스타일 방향 (확정, 바꾸지 않는다)
**기존 README 히어로의 회화풍(유화풍) 다크 판타지를 이어간다.** 새 스타일을 만들지 않는다.
기존 히어로: 폭풍 바다에서 브리칭하는 범고래, 머리 위 빛나는 왕관, 피부에 발광 문양, 신광, 딥 티얼–차콜.

## 신화 훅
네레우스는 바다의 노인이자 예언자다. **거짓을 말하지 않지만 모습을 바꿔 도망친다 —
붙잡고 놓지 않아야 진실을 말한다.** 이 하네스가 하는 일이 그것이다. 그래서 피부의 문양은
장식이 아니라 **"몸에 새겨진 차단 규칙"** 이다.

## 구도 — 기계적 수직 2분할 금지
좌 1/3 텍스트 / 우 2/3 일러스트로 반듯이 자르지 않는다. 정적인 배너가 된다.
- 범고래는 **완만한 아크**로 브리칭한다. 우하에서 올라오되 곧게 치고 나가지 않는다 —
  등 곡선과 시선 끝이 **좌측 텍스트를 감싸며 떨어져 시선 루프를 닫는다.**
  직선 대각선은 운동 에너지를 캔버스 좌상단 밖으로 밀어낸다.
- 전면 물보라는 **텍스트 바운딩 박스 하단 패딩 외곽까지만** 파고든다.
  **글자 면과의 오버랩 절대 금지** — 밝은 포말이 글리프 하단 획과 엉켜 가독성을 파괴한다.
- 텍스트 영역은 좌측에서 최대 **45% 폭까지** 쓰고, **수직으로는 캔버스 중앙(Y 45~55%)에
  엄격히 앵커링**한다. 위로 올리면 왕관·신광 궤적과 물리적으로 겹친다.
- 안전 여백: 좌우 **80px**, 상하 **60px**. 트위터·슬랙은 1.91:1 로 강제 크롭하고 플랫폼에 따라
  상하도 잘린다 — 왕관 신광 최상단, 파도 최하단, 텍스트 베이스라인이 클리핑되지 않게.

## 명도 — 텍스트 배면은 광학적으로 어두워야 한다
인위적인 블랙 페이드를 얹지 않는다(저가형 배너). 대신 **광원 위치로 어둠을 설명한다**:
주 광원(신광·왕관)은 우측 후방에서 온다 → 좌측 텍스트 영역은 자연히 **역광의 암부**가 된다.
- 해무(mist)는 **원경과 고래 사이에만** 둔다. 텍스트 배면까지 끌고 오지 않는다 —
  해무로 배경을 들어올린 뒤 밝은 텍스트를 얹으면 대비가 정면 충돌한다.
- 텍스트 배면 = 딥 티얼·차콜 암부의 네거티브 스페이스.
- **림 라이트 필수**: 브리칭 실루엣 외곽을 강한 림 라이트·백라이트로 딴다.
  없으면 딥 티얼 해수와 범고래 흑색부가 축소 시 하나의 어두운 덩어리로 뭉개진다.

## 팔레트 — 광원 2개, 색온도로 분리
바다: 딥 티얼(#0d2b33) → 차콜(#11161a). 범고래: 흑–백 2톤.
- **주 광원 = 신광·왕관**: 차가운 화이트–페일 골드. 넓고 부드럽게. 신성·권위.
- **부 광원 = 피부 문양**: 시안–민트(#7fe3d4), 높은 채도, 좁고 날카로운 발광.
  왕관과 같은 빛으로 칠하면 은유가 죽고 흔한 판타지 장식이 된다.
- **림 라이트는 페일 골드로 단일화한다.** 시안은 전면 앰비언트 반사광에만 쓴다 —
  외곽을 두 광원이 섞으면 실루엣이 탁하게 오염된다.
- 액센트 발광은 이 둘뿐. README 배지 `#1f4e79` 와 충돌하지 않게.

## 피부 문양 = 구속 링(Constraint Band) — 이 도구의 정체
미세한 코드 글리프를 세밀화하지 않는다(축소 시 픽셀 노이즈). 그리스 룬풍 임의 곡선도 금지.
**범고래의 유선형 신체를 물리적으로 구속·제어하는 굵직한 기하학적 링**으로 결속한다.
타투가 아니라 **몸을 가로지르는 관문**이다. 멀리서 실루엣만 봐도 그렇게 읽혀야 한다.
이것이 "판타지 RPG 키아트"와 "개발자 도구"를 가르는 유일한 형태 언어다.

## 타이포 — 구조적 대비 페어링, 화풍과 표면 일체화
- 워드마크 `NEREUS`: **아키텍처럴 산세리프 대문자**, 장중한 무게감, 넓은 자간.
  **1280px 기준 108~120px.** 1차 시각 앵커다.
- 태그라인 한 줄: `Harness for Claude Code`. **최소 40px**, x-height 가 큰 지오메트릭/테크니컬
  산세리프(Space Grotesk 계열). 순수 타자기풍 모노스페이스는 장중한 워드마크와 양식이 충돌한다.
- **워드마크:태그라인 크기 대비 최소 2.5:1.** 이 계층이 무너지면 시선 순서가 사라진다.
- **텍스트 고유색**: 플랫 화이트로 두지 않는다. 페일 골드 틴트를 15~20% 섞는다.
- 얇은 구분선 금지(축소 시 소실). **파이프라인 5단계 메타데이터 금지** — 360px 안에
  워드마크·태그라인과 함께 넣으면 전부 붕괴한다.
- **텍스트 외곽은 100% 날카로운 벡터 엣지를 유지한다.** 외곽 블러·디퓨전을 주면 300px
  축소 피드에서 앤티앨리어싱이 깨져 저화질 압축 노이즈처럼 보인다. 유화 배경과의 표면
  일체감은 **텍스트 내부의 페일 골드 그라디언트와 미세 이너 섀도로만** 해결한다.

## 제약
- 300~400px 폭에서 워드마크·태그라인·범고래 실루엣이 모두 읽혀야 한다. 이것이 합격 기준.
- 우하단 구석은 파도·여백으로 비워 둔다(생성 워터마크가 그 자리에 찍히므로 덮을 여지를 남긴다).
- 사람·실존 인물 없음. 텍스트는 영문만(한글 렌더 품질 불안정).

## Ruling — 방향 라운드 4회에서 렌더 판정으로 전환 (2026-09-07)
Gemini 방향 비평 4라운드를 돌렸다. 1~3라운드는 구조를 실제로 고쳤다(모순된 명도 지시, 기계적
2분할, 발광 위계, 문양의 추상화 수준). 그러나 4라운드가 **3라운드 자신의 지시를 뒤집었고**
(텍스트 엣지 디퓨전 → 디퓨전 금지), 남은 지적이 전부 이미지 생성 모델이 지키지 못하는 픽셀
수치(32 vs 40px, Y축 45~55%, 이너 섀도)로 옮겨갔다. 방향은 3라운드에서 수렴했다고 판단해
모순 없는 항목만 반영하고 렌더 라운드(visual)로 넘긴다. 남은 수치 항목은 렌더 결과에서
실제로 읽히는지로 판정한다 — 그것이 애초에 이 지적들의 목적이다.
